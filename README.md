# Submit-Quest-JavaScript じゃんけんゲーム

## 概要

JavaScriptの基礎学習として制作した、じゃんけんゲームです。
プレイヤーは「グー・チョキ・パー」から手を選択し、CPUとじゃんけんを行います。
通常モードではCPUがランダムに手を選択しますが、チートモードをONにすると、CPUが必ずプレイヤーに負ける手を選択する仕組みになっています。JavaScriptによる条件分岐・ランダム処理・状態管理・DOM操作などの基礎的な処理を実践的に学ぶことを目的として制作しました。

## 主な機能

* グー・チョキ・パーによるじゃんけん
* CPUの手をランダムに決定
* 勝敗結果の表示
* チートモードのON/OFF切り替え
* チートモード時にプレイヤーが必ず勝利
* 勝敗結果に応じたネオン風の文字色変更
* チートモードON時の背景アニメーション

## 使用技術

* HTML
* CSS
* JavaScript
